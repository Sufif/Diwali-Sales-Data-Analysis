🪔 Diwali Sales Data Analysis

📌 Project Overview

This project focuses on analyzing Diwali sales data using Python to understand customer purchasing behavior, sales patterns, and business performance.

The analysis includes data cleaning, exploratory data analysis (EDA), aggregation, and visualization to identify meaningful patterns across different customer and product segments.

📊 Dataset

The dataset contains 11,251 sales records and customer/order-related information such as:

- Customer ID
- Customer Name
- Product ID
- Gender
- Age
- Age Group
- Marital Status
- State
- Zone
- Occupation
- Product Category
- Orders
- Amount

🧹 Data Cleaning

The following preprocessing steps were performed:

- Removed unnecessary columns such as "Status" and "unnamed1"
- Removed records containing missing values
- Converted the "Amount" column to integer format
- Checked dataset structure and missing values
- Used descriptive statistics to understand numerical variables

🔍 Exploratory Data Analysis

The project analyzes:

👥 Customer Demographics

- Gender distribution
- Age-group distribution
- Marital status

📍 Geographic Analysis

- State-wise order volume
- State-wise sales amount
- Top-performing states

💼 Occupation Analysis

- Customer distribution by occupation
- Sales generated by different occupations

🛍️ Product Analysis

- Product category distribution
- Order patterns across product categories

📈 Sales Analysis

- Gender-wise sales
- Age-group-wise sales
- State-wise sales
- Occupation-wise sales

📊 Visualizations

Seaborn and Matplotlib were used to create visualizations including:

- Bar charts
- Count plots
- Category comparisons
- Sales and order comparisons

These visualizations make it easier to identify customer segments and sales trends.

🛠️ Tech Stack

- Python
- Pandas
- NumPy
- Seaborn
- Matplotlib
- Jupyter Notebook

💡 Key Insights

The analysis helps identify:

- Differences in purchasing behavior across genders
- High-performing customer age groups
- States generating higher order volumes and sales
- Occupations contributing significantly to revenue
- Popular product categories
- Customer segments that can be targeted for future marketing campaigns

🎯 Business Objective

The primary objective of this project is to demonstrate how raw sales data can be cleaned, explored, visualized, and transformed into useful business insights that can support customer targeting and sales strategy.
